# Fullstack Todo List — Next.js App Router + Bulletproof React

Полноценное CRUD-приложение для управления задачами с серверными API-маршрутами (Route Handlers), строгой валидацией данных и кэшированием запросов. Проект организован по модульной архитектуре **Bulletproof React**.

## Основной функционал
- **Полный CRUD:** создание, просмотр, редактирование текста («Изменить»), переключение статуса выполнения и удаление задач.
- **Серверный API на Next.js:** обработка HTTP-запросов (`GET`, `POST`, `PATCH`, `DELETE`) через App Router Route Handlers (`/api/todos` и `/api/todos/[id]`).
- **Валидация на двух уровнях:** проверка входящих данных через **Zod** как в формах на клиенте, так и в серверных обработчиках перед записью в базу.
- **Фильтрация списка:** мгновенная фильтрация задач («Все», «Активные», «Выполненные») через глобальный стейт без лишних запросов к серверу.

## Стек технологий
- **Next.js 16 (App Router)** — клиентская часть и серверные Route Handlers
- **TypeScript 6** — строгая типизация и вывод типов из Zod-схем (`z.infer`)
- **Tailwind CSS v4** — адаптивная верстка интерфейса
- **Redux Toolkit (RTK Query + Slice)** — кэширование серверных данных, автоматическая инвалидация тегов (`providesTags` / `invalidatesTags`) и управление состоянием фильтров
- **Zod** — схемная валидация DTO и пользовательского ввода
- **Node.js `fs/promises` (`db.json`)** — локальное файловое хранилище (с поддержкой `/tmp` для serverless-окружения Vercel)

## Архитектура проекта (Bulletproof React)
```text
src/
├── app/                   # Роутинг Next.js, API Route Handlers и глобальный Provider
├── features/
│   └── todos/             # Изолированный бизнес-модуль задач (api, components, store, types, index.ts)
├── lib/                   # Базовый клиент RTK Query и утилиты работы с файловой системой
└── store/                 # Конфигурация Redux Store
```

## Локальный запуск
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
3. Откройте [http://localhost:3000](http://localhost:3000) в браузере.
